## Scientific scope

- ORCID fields are **assertions in public records**, not independent verification of identity, authorship, affiliations, or project membership.
- An edge between two researchers in Group view means **both public records list the same DOI**, not that their collaboration has been independently established.
- Funder-format biosketches are editable drafts, **not validated submissions**.
- A **local curated Group** (My Network, in this browser), a **Public Group View link** (a group name and public iDs) and a **private cloud Team** are different things. Private cloud Teams are experimental and **not available** on the public site. Read the [privacy and availability guide](trust.md) first.

**{{ disclaimer }}** Public data are read through the [ORCID Public API](https://info.orcid.org/what-is-orcid/services/public-api/). {{ trademark }}
