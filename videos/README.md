# Demo videos

All videos show the web app's UI only. Rendered by `demo/render.mjs` and `demo/groups.mjs` (see `demo/README.md`).

- `studio/` — full demo (~104 s, 1280x720) and `clip-0…6` (1080x1080) for LinkedIn.
- `groups/` — working-group demo (~129 s, 1280x720) and `groups-clip-1…6` (1080x1080).
- `contacts/` — Contacts demo (~67 s, 1280x720) and `contacts-clip-1…4` (1080x1080).

The Studio videos use the maintainer's stored profile and the network app's labelled Demo data.
The Group view part of the groups demo uses four fictional "(Demo)" researchers with synthetic ORCID records
(`demo/synthetic.mjs`); no real person's record appears in it.

The Contacts demo also uses the synthetic "(Demo)" researchers; its tags, notes and follow-ups are typed live.
